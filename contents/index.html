1. Start Here

Computer, game, programming, and hacking fundamentals; a Rust primer, safe lab, memory model, and first value scan. About 4.7 hours.

    Learn a simple way to look up an unfamiliar idea, explain it accurately, correct mistakes, and remember it later.

    14 min
  2. 1.2How a Computer Runs a Game

    Build a game from CPU instructions, a small program, stored values, and the services that make it interactive.

    16 min
  3. 1.3Game Fundamentals

    Follow a game's input, rules, changing state, and display; then grow one player's values into records and collections.

    21 min
  4. 1.4Programming Fundamentals

    Build a small Rust program and use it to understand logic, collections, and ways to organize code.

    35 min
  5. 1.5A Rust Primer for the Game Labs

    Express programming logic in Rust: name state, choose a path, repeat work, group values, borrow safely, and handle missing or failed results.

    48 min
  6. 1.6Hacking Fundamentals

    Turn an observed game behavior into a testable question, narrow possible causes, and make one reversible change with a four-step method.

    18 min
  7. 1.7Build a Safe Windows Lab

    Set up a Windows virtual machine with the compiler, debugger, memory scanner, course code, and recovery snapshots.

    16 min
  8. 1.8How Memory Actually Works

    Trace one game value through bytes, types, addresses, pointers, and offsets, then see why a found address can change.

    25 min
  9. 1.9Your First Memory Experiment

    Find, test, and change one gold value in Wesnoth, and see what each scan does and does not prove.

    18 min
  10. 1.10From Source Code to a Running Program

    Compare native compilation, bytecode interpretation, REPLs, and type checking; then follow a native program through linking and loading.

    28 min
  11. 1.11What a Game Engine Is

    Separate the reusable engine from the game built on it, see which engine each course game uses, and learn why where a rule lives decides how you change it.

    18 min
  12. 1.12What Any Computer Can Compute

    Build a Turing machine by hand, see why one computer can run every program, and learn which questions about programs no tool can always answer.

    22 min
