How Pointer Paths Survive Restarts

Trace the player object back to a verified starting point and prove the pointer path across restarts.

About 20 minutes

Section: A pointer path is a route through an object graph.

Each dereference moves from one object to another. The observed root hexadecimal 0 1 7 E E D 1 8 is an absolute address for the pinned course build, not an RVA, relative virtual address,. Confirm that it still points into the expected module in your run. A portable profile would store the root’s RVA and first discover the module’s current base, as Lesson 2.7 explained. The heap objects reached afterward may move between runs, which is why the path reads their current addresses rather than saving yesterday’s final address.

A path is stable only under stated conditions. It may depend on:

the exact executable build;

a local match being active;

the current player or side object existing;

the same layout and pointer width;

each intermediate page being readable at the moment of use.

Validate every edge, not only the final gold. A non-null pointer can still be stale or point to the wrong object. Check module ranges, page protections, alignment, and a few field invariants before trusting the final value.

Section: Restart tests.

One successful run proves very little. Test:

close Wesnoth completely;

start it again;

begin a new local match;

confirm the pointer entry resolves;

repeat at least three times.

Also test a state where no match is active. A good tool should report “player object unavailable,” not crash or read address zero.

Section: What counts as “stable”.

The path is stable only for the target version and states you tested. The absolute root in this example also depends on the module loading where it did in the verified course run; a relocated module requires base-plus-RVA resolution. Game updates can change layouts and offsets. Document:

game version and architecture;

module name;

offsets in traversal order;

the expected final type;

how many restarts passed;

known states where the chain is unavailable.
