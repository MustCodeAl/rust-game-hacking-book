The book publishes two plain-text files for AI assistants and search tools.
They follow the [llms.txt](https://llmstxt.org) convention, so many tools find
them on their own.

| File | What it holds | Use it when |
|---|---|---|
| [`llms.txt`](/llms.txt) | A short guide: what the book covers, which chapter answers which topic, key vocabulary, and a link to every lesson | an assistant needs to find the right lesson |
| [`llms-full.txt`](/llms-full.txt) | The full text and code of every lesson in one file | an assistant needs the actual explanation and code |

The repository also contains a `docs.json` file that lets
[Context7](https://context7.com) index the lessons chapter by chapter, so
coding assistants that use Context7 can look up a lesson while you work.

## Getting accurate answers

An assistant answers best when it can see the lesson the question is about.
Paste the lesson's link or text into the conversation, or point the assistant
at `llms-full.txt`, rather than relying on what it remembers.

Addresses, offsets, and byte patterns belong to one exact build of one game.
An assistant cannot know them for a build it has not seen, and it may still
produce numbers that look plausible. Treat any such number as unverified until a
debugger, a scanner, or the game's own files confirm it.

The book's labs are small, deterministic programs. When an assistant suggests a
change to one, run the lab's compile and test commands from the `rust-labs`
README before trusting the result.
