## Parsing is careful reading

Suppose local captures suggest this frame:

```text
u32 big-endian compressed length
u32 big-endian uncompressed length
zlib-compressed payload
```

Inside the payload, a chat message contains a kind, sender, and text. Treat this as a hypothesis until tests confirm it.

## Read with a cursor

```rust
#[derive(Debug)]
enum ParseError {
    Truncated,
    TooLarge(usize),
    InvalidUtf8,
    UnknownKind(u8),
}

struct Cursor<'a> {
    bytes: &'a [u8],
    position: usize,
}

impl<'a> Cursor<'a> {
    fn take(&mut self, count: usize) -> Result<&'a [u8], ParseError> {
        let end = self.position.checked_add(count).ok_or(ParseError::Truncated)?;
        let slice = self.bytes.get(self.position..end).ok_or(ParseError::Truncated)?;
        self.position = end;
        Ok(slice)
    }

    fn u8(&mut self) -> Result<u8, ParseError> {
        Ok(self.take(1)?[0])
    }

    fn u32_be(&mut self) -> Result<u32, ParseError> {
        Ok(u32::from_be_bytes(
            self.take(4)?.try_into().map_err(|_| ParseError::Truncated)?,
        ))
    }
}
```

Every read checks its boundary.

## Decode length-prefixed text

```rust
impl Cursor<'_> {
    fn string(&mut self, max: usize) -> Result<String, ParseError> {
        let length = self.u32_be()? as usize;
        if length > max {
            return Err(ParseError::TooLarge(length));
        }
        let bytes = self.take(length)?;
        std::str::from_utf8(bytes)
            .map(str::to_owned)
            .map_err(|_| ParseError::InvalidUtf8)
    }
}
```

The limit matters even in a local tool. Never allocate directly from an untrusted length with no ceiling.

## Parse the payload

```rust
#[derive(Debug, Eq, PartialEq)]
enum Message {
    Chat { sender: String, text: String },
    Ping,
}

fn parse_message(bytes: &[u8]) -> Result<Message, ParseError> {
    let mut cursor = Cursor { bytes, position: 0 };

    match cursor.u8()? {
        1 => Ok(Message::Chat {
            sender: cursor.string(64)?,
            text: cursor.string(1_024)?,
        }),
        2 => Ok(Message::Ping),
        kind => Err(ParseError::UnknownKind(kind)),
    }
}
```

Do not use a wildcard that silently turns unknown kinds into chat.

## Serialize separately

```rust
fn push_string(out: &mut Vec<u8>, value: &str) -> Result<(), &'static str> {
    let length = u32::try_from(value.len()).map_err(|_| "string too long")?;
    out.extend_from_slice(&length.to_be_bytes());
    out.extend_from_slice(value.as_bytes());
    Ok(())
}

fn encode_message(message: &Message) -> Result<Vec<u8>, &'static str> {
    let mut out = Vec::new();
    match message {
        Message::Chat { sender, text } => {
            out.push(1);
            push_string(&mut out, sender)?;
            push_string(&mut out, text)?;
        }
        Message::Ping => out.push(2),
    }
    Ok(out)
}
```

## Add compression after plain parsing works

Use `flate2`:

```toml
[dependencies]
flate2 = "1"
```

Decode into a limited buffer and verify the advertised uncompressed size. Compression can turn a small input into a huge output, so enforce a maximum.

## Round-trip tests

```rust
#[test]
fn chat_round_trip() {
    let original = Message::Chat {
        sender: "lab-user".into(),
        text: "hello-17".into(),
    };

    let encoded = encode_message(&original).unwrap();
    let decoded = parse_message(&encoded).unwrap();
    assert_eq!(decoded, original);
}
```

Also test empty input, truncated fields, invalid UTF-8, unknown kinds, oversized lengths, and extra trailing bytes.

![Comparing one changed message field](/assets/images/6/3/packet14.png)

The goal is not merely to make one capture parse. It is to define exactly which byte strings are accepted and how malformed data fails.
