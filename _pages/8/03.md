## Identify one surface

In the offline Urban Terror target, choose a distinctive wall, sign, or object. Walk close enough to see its texture clearly.

![A distinctive in-game surface](/assets/images/8/3/urbanterror1.png)

Search the game’s resource folders or archives for likely image names. Thumbnail tools and image dimensions can narrow the list.

Urban Terror’s `q3ut4` folder contains `.pk3` files. A PK3 is a ZIP archive with a game-specific extension; its first two bytes are the ZIP magic `PK`. For this exact lab, open:

```text
q3ut4\zUrT43_001.pk3
```

Inside it, browse to `env\austria`. These six images form the Austria map’s skybox.

## Prove the file

Make a reversible test change—such as a bright corner mark—while preserving:

- width and height;
- color channels;
- alpha behavior;
- compression format;
- mipmap expectations;
- file name and path.

![A candidate texture file](/assets/images/8/3/urbanterror3.png)

Restart or reload the level. If the mark appears on the chosen surface, the mapping is confirmed.

## Perform the Austria skybox hack

Extract `zUrT43_001.pk3` to a work folder. Keep the original PK3 as a backup. In the extracted tree:

1. delete `env\austria\austriasky_up.jpg`;
2. copy `env\austria\austriasky_dw.jpg`;
3. rename the copy to `austriasky_up.jpg`;
4. ZIP the archive’s **contents** (`botfiles`, `env`, `fonts`, and the other root folders), not the outer work folder;
5. name the new archive `zUrT43_001.pk3` and place it in `q3ut4`.

Start a local match on `ut4_austria` and look upward. The top of the sky now uses the downward-facing image. That unmistakable result proves you found, modified, and repacked the real game resource correctly.

## Run the complete Rust PK3 replacer

Close Urban Terror and give the tool the real archive path:

```powershell
.\target\i686-pc-windows-msvc\release\urbanterror_pk3.exe `
  "C:\Games\UrbanTerror\q3ut4\zUrT43_001.pk3"
```

The program opens the PK3 as ZIP, reads `env/austria/austriasky_dw.jpg`, rebuilds every archive entry, substitutes those bytes only for `env/austria/austriasky_up.jpg`, flushes the new archive, and atomically installs it with `ReplaceFileW`. The untouched original becomes `zUrT43_001.pk3.gha-backup`, and the tool refuses to replace any other PK3 name or overwrite that backup.

The full implementation is [`urbanterror_pk3.rs`](/windows-labs/src/bin/urbanterror_pk3.rs). It uses the current `zip` crate API documented through Context7 and the shared Windows replacement helper in [`file_replace.rs`](/windows-labs/src/windows_impl/file_replace.rs).

<summary>Complete lab source: urbanterror_pk3.rs</summary>

```rust
#[cfg(windows)]
fn main() -> anyhow::Result<()> {
    use std::{
        fs::{self, File},
        io::{Read, Write},
        path::{Path, PathBuf},
    };

    use anyhow::Context;
    use gha_windows_labs::replace_file_with_backup;
    use zip::{ZipArchive, ZipWriter, write::SimpleFileOptions};

    const UP: &str = "env/austria/austriasky_up.jpg";
    const DOWN: &str = "env/austria/austriasky_dw.jpg";
    const MAX_SKY_FACE: u64 = 32 * 1024 * 1024;

    fn read_down_face(path: &Path) -> anyhow::Result<Vec<u8>> {
        let mut archive = ZipArchive::new(File::open(path)?)?;
        let mut entry = archive
            .by_name(DOWN)
            .with_context(|| format!("{DOWN} is missing from the PK3"))?;
        anyhow::ensure!(
            entry.size() <= MAX_SKY_FACE,
            "sky image is unexpectedly large"
        );
        let mut bytes = Vec::with_capacity(usize::try_from(entry.size())?);
        entry.read_to_end(&mut bytes)?;
        anyhow::ensure!(!bytes.is_empty(), "downward sky image is empty");
        Ok(bytes)
    }

    let path = PathBuf::from(
        std::env::args()
            .nth(1)
            .context("usage: urbanterror_pk3 <path-to-zUrT43_001.pk3>")?,
    );
    anyhow::ensure!(
        path.file_name()
            .is_some_and(|name| name == "zUrT43_001.pk3"),
        "this lab accepts only zUrT43_001.pk3"
    );
    let replacement = read_down_face(&path)?;
    let temporary = path.with_extension("pk3.gha-new");
    let backup = path.with_extension("pk3.gha-backup");
    anyhow::ensure!(!temporary.exists(), "temporary PK3 already exists");

    let mut archive = ZipArchive::new(File::open(&path)?)?;
    let output = File::create(&temporary)?;
    let mut writer = ZipWriter::new(output);
    let mut replaced = 0_usize;

    for index in 0..archive.len() {
        let mut entry = archive.by_index(index)?;
        let name = entry.name().to_owned();
        let options = SimpleFileOptions::default()
            .compression_method(entry.compression())
            .unix_permissions(entry.unix_mode().unwrap_or(0o644));

        if entry.is_dir() {
            writer.add_directory(name, options)?;
            continue;
        }
        writer.start_file(&name, options)?;
        if name == UP {
            writer.write_all(&replacement)?;
            replaced += 1;
        } else {
            std::io::copy(&mut entry, &mut writer)?;
        }
    }
    anyhow::ensure!(replaced == 1, "expected one {UP} entry, found {replaced}");
    let output = writer.finish()?;
    output.sync_all()?;

    if let Err(error) = replace_file_with_backup(&path, &temporary, &backup) {
        let _ = fs::remove_file(&temporary);
        return Err(error);
    }
    println!(
        "Replaced {UP} with {DOWN}. Original archive saved at {}.",
        backup.display()
    );
    Ok(())
}

#[cfg(not(windows))]
fn main() {
    eprintln!("This PK3 replacement lab uses ReplaceFileW and must run on Windows.");
}
```

</details>

The loop rebuilds every entry instead of modifying ZIP bytes in place. Only the exact `UP` path receives replacement bytes, and `replaced == 1` catches both “wrong archive” and “duplicate path” mistakes before Windows installs anything.

## Inspect image metadata in Rust

The `image` crate can load common formats:

```toml
[dependencies]
anyhow = "1"
image = "0.25"
```

```rust
use image::GenericImageView;
use std::path::Path;

fn inspect_texture(path: &Path) -> anyhow::Result<()> {
    let image = image::open(path)?;
    let (width, height) = image.dimensions();
    println!(
        "{}: {width}×{height}, {:?}",
        path.display(),
        image.color()
    );
    Ok(())
}
```

Some game-specific formats need dedicated tools. Do not rename a PNG to another extension and assume the bytes changed format.

## Create a marked copy

```rust
use image::{Rgba, RgbaImage};

fn add_corner_marker(mut image: RgbaImage) -> RgbaImage {
    let width = image.width().min(16);
    let height = image.height().min(16);

    for y in 0..height {
        for x in 0..width {
            image.put_pixel(x, y, Rgba([255, 64, 32, 255]));
        }
    }
    image
}
```

Write to a new path first and compare dimensions and color type.

## Loose files and archives

Some engines prefer a loose file over the same path inside an archive. Others require rebuilding the archive.

If extracting:

- keep the directory structure;
- reject absolute and parent-traversal paths;
- preserve the original archive;
- change one entry only;
- use the engine’s official packer when available.

## Texture coordinates explain repetition

A model stores UV coordinates that map its surface to the image. One texture can repeat, rotate, or cover many surfaces. Changing the image may affect more places than the one you first noticed.

![The replacement texture in game](/assets/images/8/3/urbanterror7.png)

## Package as a mod

Prefer a mod directory containing only the changed file and a short manifest:

```text
name: orange-corner-texture
target: Urban Terror 4.3.4
source path: textures/example/wall.tga
original sha256: ...
changes: 16×16 orange marker in top-left
uninstall: remove the mod folder
```

Do not redistribute original copyrighted assets when a small patch, generated replacement, or installation script is enough.
