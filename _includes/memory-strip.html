{%- comment -%} Draws a row of labelled boxes: bytes at addresses, fields in an object, cells on a Turing machine tape. With column=true the boxes run top to bottom instead, which suits stacks and address-space maps. cells required "label=value|label=value|..." The label sits above the box (beside it in a column) and is usually an address or an offset. Either half may be empty: "=64" or "0x1000=". marks optional "2" or "0-3|6": zero-based boxes to highlight. groups optional "0-3:read as u32 gives 100|4-7:..." braces spanning boxes. groups2 optional a second row of braces, for a competing reading of the same boxes. caption optional Markdown allowed. label optional accessible name for the figure when the caption alone does not describe it. The boxes themselves stay readable text, so a screen reader still reaches every value. The output is written with no indentation and no blank lines, because kramdown would otherwise treat indented HTML as a code block and a blank line as the end of the HTML. {%- endcomment -%} {%- assign mem_cells = include.cells | split: "|" -%} {%- assign mem_marks = include.marks | default: "" | append: "" | split: "|" -%} {%- assign mem_rows = "" | split: "," -%} {%- if include.groups -%}{%- assign mem_rows = mem_rows | push: include.groups -%}{%- endif -%} {%- if include.groups2 -%}{%- assign mem_rows = mem_rows | push: include.groups2 -%}{%- endif -%}
